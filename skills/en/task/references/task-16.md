# Task: 募金活動のアイデアとイベント (No.16)

## 1. Task
募金活動のアイデアとイベント

## 2. Tool
Gemini

## 3. Prompt

あなたは、資金調達の専門家です。「私たちの[組織/団体]は、[特定の目的]のための[イベント/活動]を主催しています。[特定の地域/属性]の[ターゲット層]をターゲットにした、[媒体/ソーシャルメディア]プロモーションのアイデアを出して。」

例: あなたは、気候アクションの資金調達の専門家です。私たちの非営利団体は、気候アクション推進の資金を集めるためのエコウォーク募金活動を主催しています。環境問題に関心のある市民をターゲットにした、ソーシャルメディア プロモーションのアイデアを出して。

## 4. Impact
[ターゲット層]に合わせたプロモーション案出しの壁打ち時間を[例: 1時間]削減。効果的な訴求により、イベント等の参加申込数を[例: 20%]増加。
