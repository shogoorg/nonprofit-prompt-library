# Task: マーケティング (No.37)

## 1. Task
マーケティング

## 2. Tool
Gemini

## 3. Prompt

あなたは非営利団体の誠実な事務局スタッフです。
以下の【今回の活動結果】をもとに、日頃から応援してくれている寄付者・サポーターへ送る「お礼メール」を作成してください。

# メールの構成
1. 感謝の挨拶
2. 今回の活動で得られた具体的な成果（数字など）
3. 現場スタッフからのひとこと（温度感のあるエピソード）
4. これからも応援をよろしくお願いいたしますという結び

# 制約事項（ハルシネーション防止策）
・感謝を伝えるために、架空の「支援された人の感動エピソード」を勝手に作らないでください。エピソードが必要な部分は「（※ここに現場であった具体的な嬉しかった出来事を1行追記）」とプレースホルダーを置いてください。

【今回の活動結果】
・活動の内容：https://nerimakodomo9.jugem.jp/?eid=348　[ 例：都内3箇所でのフードバンク食料配布 ]
・今回の成果：あさりより、蛤が沢山取れた。当日潮干狩り場で、じゃんけん大会が行われていました。勿論、ねりまこども食堂のみんなも参加しました。その結果、なんと、1位と2位をねりまこども食堂の子が取りました！1位の商品はお米、2位は海苔の詰め合わせでしたおめでとう！[ 例：合計120世帯に食材をお渡しできた ]
・参加したボランティア数：10名　[ 例：15名 ]
・特筆すべきこと：潮干狩りは初めてという親子が殆どで、楽しんでくれました。うちの子は「楽しかったなぁ～」と毎日言っているんですよ！ママたちも張り切って、普段作らない「アサリの酒蒸し」や「蛤のお吸い物」「アサリのパスタ」など作ったそうです。子供達は、「貝の砂抜き」を覚えたそうです。バスツアー、次回はどこへ行きましょうか？　[ 例：今回は初めて地元の中学生がボランティアで手伝ってくれた ]

## 4. Impact
想定ケース：支援者向けの「お礼メール（活動報告）」作成
ターゲット (Who): 寄付者やボランティアへのメール配信を行う事務局スタッフ

課題 (Problem): 毎回同じような定型文になってしまい、感謝の熱意が伝わるバリエーションを出せない。

解決策 (Solution): 今回の活動トピックと数値を入力し、感謝を伝える文面を自動生成させる。

効果 (Benefit): 支援者の継続応援意向の維持、事務作業の心理的負荷軽減。

想定インパクト: 例、メール1通あたりの作成時間を約80%削減（平均25分 ⇒ 約5分）
