# Task: マーケティング (No.33)

## 1. Task
マーケティング

## 2. Tool
Gemini

## 3. Prompt

あなたは非営利団体の優秀な広報担当者です。
以下の【イベント情報】をもとに、SNS（XやFacebook）で発信する告知文を3つのトーンで作成してください。

# 出力トーンの条件
・パターンA：親しみやすく、絵文字を適度に用いたトーン
・パターンB：誠実で真面目な、信頼感のあるトーン
・パターンC：参加者の「得られるメリット」を一番に強調したトーン

# 制約事項（ハルシネーション防止策）
1. 【イベント情報】に記載されている事実のみを使用してください。
2. 情報にない「日時」「場所」「登壇者の経歴」「背景」を勝手に想像して補完しないでください。
3. 原稿として情報が不足している箇所は、推測で書かず「（※ここに〇〇を追記）」と出力してください。

## 4. Impact
想定ケース：イベント集客用の「SNS告知文」作成
ターゲット (Who): SNS発信に不慣れな、団体の広報担当スタッフ・ボランティア

課題 (Problem): 告知文をゼロから考えるのに時間がかかり、更新頻度が落ちてしまう。

解決策 (Solution): イベントの基本情報を箇条書きで入力し、読者層に合わせた3つのトーンを同時作成させる。

効果 (Benefit): 執筆への心理的ハードルを無くし、SNSの定期発信を習慣化できる。

想定インパクト: 例、作成時間を1件あたり約75%削減（平均40分 ⇒ 約10分）
