# Task: 助成金申請書 (No.02)

## 1. Task
助成金申請書

## 2. Tool
Gemini

## 3. Prompt

私たちの非営利団体は、「特定非営利活動法人「ねりまこども食堂」[助成金提供団体名]」 に助成金を申請する予定です。
以下の【助成金の公募要領】と【私たちの事業概要】を基に、以下の3点を書き出してください。

この資金提供者が最も重視している優先事項と審査基準を3〜4点に要約してください。

私たちの事業概要の中で、その優先事項に最も強く合致するアピールポイントを3点挙げてください。

申請書の導入部（背景と目的）として、資金提供者の趣旨に寄り添った説得力のある文章を300文字程度で2パターン作成してください。

【助成金の公募要領】：https://www.city.nerima.tokyo.jp/hokenfukushi/chiikifukushi/kodomodanran.html（ここに公募要領をコピーして貼り付けるか、URLを入力）
【私たちの事業概要】：https://nerima-kodomo.net/about.html（ここに自団体のミッション、解決したい地域課題、対象者などの情報を貼り付けるか、URLを入力）

## 4. Impact
・長大で複雑な助成金募集要項の読み解きにかかる時間を削減
・資金提供者の意図と自団体の強みを出す。
・趣旨に合致しない的外れな申請を防ぎ、書類作成の初動スピードが大幅に向上
