# Task: マーケティング (No.31)

## 1. Task
マーケティング

## 2. Tool
ChatGPT

## 3. Prompt

あなたはNPOの広報担当です。以下の情報をもとに、活動内容を紹介するブログ記事を作成してください。

【入力項目】

①活動概要
（例：子ども食堂を開催し、地域の子どもと保護者約30名が参加）

②活動の背景
（例：地域で安心して過ごせる居場所づくりを目的として開催）

③当日の出来事
（例：参加者同士で食事や交流を楽しみ、ボランティアによる読み聞かせを実施）

④参加者の声や成果
（例：「また参加したい」という感想が寄せられた、新しい地域のつながりが生まれた）

⑤今後の予定
（例：来月も開催予定、次回イベントの案内）

⑥団体紹介
（例：NPO法人みらいスマイル。子ども食堂や学習支援、地域交流活動を行う団体）

⑦掲載媒体（任意）
（例：ホームページ、お知らせページ、note）

【出力条件】
1. 記事タイトル
2. 本文
3. 読者に伝えたいポイント（要約・任意）
800～1,200文字程度で、一般読者にも分かりやすく、活動の意義や魅力が伝わる構成にしてください。
誇張表現や事実にない内容は記載しないでください。

【作成ルール】
・入力された情報のみをもとに作成し、活動実績・参加人数・日時・固有名詞・参加者の感想などは推測で補完しないでください。
・情報が不足している場合は無理に補完せず、「要確認」としてください。
・活動の流れが分かりやすく伝わる構成にしてください。
・活動の意義や社会的な背景、参加者への価値が自然に伝わる内容にしてください。
・一般読者にも読みやすい文章とし、専門用語は必要に応じて分かりやすく説明してください。
・誇張表現や誤解を招く表現は避けてください。
・掲載媒体が指定されている場合は、その媒体に適した文章量・構成・表現に調整してください。
・公開前に人による確認・修正を前提としてください。

## 4. Impact
記事作成時間を短縮し、活動内容の発信頻度向上につながる。

◼️想定シーン

活動報告やイベントレポートをホームページやブログへ掲載し、活動内容や社会的な意義を支援者・地域住民・寄付者へ分かりやすく伝えたい場合。

◼️適した課題

活動内容を魅力的で分かりやすい文章にまとめられない
活動の背景や成果、社会的意義をうまく伝えられない
活動報告の記事作成に時間がかかる
読者の共感や理解につながる構成で記事を作成したい
事実に基づいた活動レポートのたたき台を効率よく作成したい
