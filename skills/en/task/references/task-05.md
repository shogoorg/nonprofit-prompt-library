# Task: 寄付者への働きかけ (No.05)

## 1. Task
寄付者への働きかけ

## 2. Tool
Gemini

## 3. Prompt

あなたは非営利団体のファンドレイジング専門のコピーライターです。
以下の【今期の活動実績データ】を基に、当団体の継続寄付者（マンスリーサポーター）に向けた「1分で読める活動報告メール」の原稿を作成してください。
単なる事実の羅列ではなく、「あなたの毎月の支援があったからこそ、この成果が生まれた」という読み手への感謝と、社会への効力感が伝わるトーンに翻訳してください。

出力構成：

- 感謝を伝える導入部

- 今期達成した「3つの大きなハイライト」（数字 ＋ その裏にある対象者の変化）

- 現場スタッフからの小さなエピソード（1つ）

- 次期への決意と、末永い伴走のお願い

【今期の活動実績データ】：https://nerima-kodomo.net/fiscal.html（ここに開催回数、参加人数、現場でのメモ等を箇条書きで貼る）

## 4. Impact
無味乾燥になりがちな活動報告を「支援者が主役のストーリー」へAIで瞬時に変換。レポート執筆時間を [例：2時間 → 30分] に短縮し、定期報告送付後におけるマンスリーサポーターの解約率を [例：15%改善] させた。
