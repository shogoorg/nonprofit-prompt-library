# Task: マーケティング (No.21)

## 1. Task
マーケティング

## 2. Tool
Gemini

## 3. Prompt

あなたは非営利団体の広報ディレクターです。
以下の【入力情報】をもとに、団体の総合紹介チラシ（A4両面または三つ折り）の紙面構成案と文章を作成してください。

# 【入力情報】
・団体名：特定非営利活動法人「ねりまこども食堂」
・団体のミッション（目指す社会の姿）：https://nerima-kodomo.net/about.html
・主な活動の柱（3つまで）：https://nerima-kodomo.net/about.html
・これまでの代表的な成果や活動実績：https://nerimakodomo9.jugem.jp/
・主なステークホルダー（誰にこのチラシを配るのか）：子ども食堂の活動にご賛同いただける全ての人
・問い合わせ先情報：https://nerima-kodomo.net/about.html

# 【出力する項目】
1. 【表紙レイアウト部】：メインキャッチコピーと団体の簡単な紹介文
2. 【中面レイアウト部】：主な活動内容（3つの柱）のわかりやすい解説
3. 【裏面レイアウト部】：団体のこれまでの歩み・実績データ、および問い合わせ先
4. 紙面全体を通して、写真を配置すべきおすすめの位置とその理由（例：活動の楽しさを伝えるため中面右に現場写真を置く、など）

# 【作成ルール】
・情報を詰め込みすぎず、余白を生かして読み手が疲れない文章量に整理してください。
・【入力情報】に記載されていない沿革、受賞歴、数値を勝手に創作しないでください。
・情報が足りない箇所は勝手に推測せず、「【要確認】」として書き出してください。
・誰にでも伝わる標準的な日本語を使用してください。

## 4. Impact
想定ケース：【総合紹介用】団体の三つ折りリーフレット・概要チラシ
1. 思考プロセス
利用対象者 (Who): 団体を設立したばかりの代表、あるいは古い案内資料を刷新したい運営スタッフ。

抱える課題 (Problem): 団体の活動が多岐にわたるため、A4用紙や三つ折りチラシの「どこに・何を書けばいいのか」というレイアウト構成（情報配置）が設計できない。

解決策 (Solution): 団体の基本概要を入力し、紙面の「表面・中面・裏面」に配置する情報設計と文章案をセットで提案させる。

得られる効果 (Benefit): 外部のデザインプロボノや印刷業者に原稿を渡す前の「情報整理の手戻り」をゼロにする。

2. 定量的インパクト
例、資料構成の設計検討時間を約3時間削減
