# Task: マーケティング (No.34)

## 1. Task
マーケティング

## 2. Tool
Gemini

## 3. Prompt

あなたは「難しい専門知識を、誰にでもわかりやすく翻訳するプロ編集者」です。
以下の【元の文章】を、専門知識がない一般の市民（高校生レベル）でもスラスラ読める活動報告コラムに書き換えてください。

# 書き換えのルール
1. 専門用語や業界用語があれば、噛み砕いた日常会話の言葉に置き換えてください。
2. 1文の長さを短くし、テンポよく読めるようにしてください。
3. 「なぜこの活動が社会に必要なのか」という理由が伝わる構成にしてください。

# 制約事項（ハルシネーション防止策）
・【元の文章】に含まれていない数値、成果、団体の歴史などを勝手に創作して書き加えないでください。事実関係は100%元の文章に準拠してください。

【元の文章もしくはURL】
https://nerima-kodomo.net/about.html　[ URLもしくはここに、団体スタッフが書いた難解な文章や、日々の業務メモをそのまま貼り付ける ]

## 4. Impact
想定ケース：専門的な活動報告の「やさしい翻訳」
ターゲット (Who): 医療・福祉・環境などの専門分野で現場活動を行う事業担当者

課題 (Problem): 専門用語や身内向けの文脈で記事を書くため、一般の寄付者や市民に価値が伝わらない。

解決策 (Solution): 現場の難解なレポートを入力し、「高校生でもわかるレベル」に要約・言い換えさせる。

効果 (Benefit): 記事の読了率・共感度向上（定性）と、推敲コストの削減。

想定インパクト: 例、難解な文章の修正・リライト時間の約60%削減（平均60分 ⇒ 約24分）
