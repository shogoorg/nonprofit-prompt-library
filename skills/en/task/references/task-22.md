# Task: マーケティング (No.22)

## 1. Task
マーケティング

## 2. Tool
Gemini

## 3. Prompt

あなたは支援対象者に寄り添うソーシャルワーカー兼ライターです。
以下の【入力情報】をもとに、困りごとを抱える方に向けた相談窓口・プログラム案内チラシの文章を作成してください。

# 【入力情報】
・提供するサポートの名称：練馬区社会福祉協議会
・対象となる方が日常で抱えている悩みや不安（具体的に）：参照PDF https://www.neri-shakyo.com/about/leaflet
・団体が提供できる解決策・サポート内容：参照PDF https://www.neri-shakyo.com/about/leaflet
・利用にかかる費用（無料の場合はその旨を強調）：参照PDF https://www.neri-shakyo.com/about/leaflet
・相談から利用開始までの簡単な流れ：参照PDF https://www.neri-shakyo.com/about/leaflet
・相談をためらっている方へ伝えたい安心メッセージ：参照PDF https://www.neri-shakyo.com/about/leaflet

# 【出力する項目】
1. 「自分のことだ」と気づいてもらうための表紙キャッチコピー（3パターン）
2. こんな悩みはありませんか？（悩みのチェックリスト案）
3. 私たちが提供できるサポート（専門用語を使わない平易な説明）
4. ご相談の流れ（わかりやすく3ステップ程度でブレイクダウン）
5. よくある不安への回答（例：秘密は守られますか？など）
6. 連絡先と「まずはお気軽にご連絡ください」という案内

# 【作成ルール】
・上から目線の指導や「救済」というトーンを完全に排除し、対等で温かく、プライバシーに配慮した表現にしてください。
・【入力情報】に書かれていない支援条件や法律・制度内容を勝手に作らないでください。
・確実な裏付けがない情報は書かず、不足部は「【団体へ確認事項】」として明記してください。

## 4. Impact
想定ケース：【利用促進用】支援対象者向けの相談窓口・サービス案内チラシ
1. 思考プロセス
利用対象者 (Who): 支援プログラムや相談事業を提供している団体の現場相談員、事業担当者。

抱える課題 (Problem): 本当に支援を必要としている人は心理的な警戒心が強いことが多いが、制度説明のようなお堅い文章になってしまい、相談のハードルを下げられていない。

解決策 (Solution): 対象者が抱えている具体的な悩みと、提供できるサポート内容を入力し、相手の気持ちに寄り添う安心感のある文面を出力させる。

得られる効果 (Benefit): 案内の作成負荷を軽減し、チラシを見た支援対象者からの相談・利用に関する最初の問い合わせ率を向上させる。

2. 定量的インパクト
例、案内文面の作成時間を約1時間短縮

例、新規の利用相談件数が約15%増加（※チラシ単体の直接的な実測根拠なし。資料内ビジネスアナリスト等のニーズ調査実績からの推計値）
